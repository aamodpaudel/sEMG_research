Research card · Afono sEMG Model

Silent speech to text with a vocabulary the interface already knows

Run baseProtocol v2Measured 2026-09-295.8M parameters

The Afono sEMG Model decodes silent speech from 8-channel facial surface EMG with a 5.8M-parameter convolutional Transformer trained with CTC on characters. Restricting the decoder to the words an interface can accept, and scoring them with a bigram word prior, raises word accuracy on a 51-word dates-and-times task from 57.6% to 95.9% (95% CI 92.5–98.8%). On free-form sentences the same model reaches 43.2% open-vocabulary word accuracy, well behind the published state of the art (87.8%). All results are from one speaker on lab hardware.

4Protocol

Data

Gaddy & Klein (2020) silent-speech EMG (DOI 10.5281/zenodo.4064408): one speaker, 8 facial channels, 1,000 Hz, about 18 hours in total. Book sentences use the official testset_largedev.json split; voiced recordings of test and dev sentences are excluded from training. The dates-and-times subset has no official split, so we hold out 10% dev and 10% test of its silent recordings by a hash of the file path. Split hashes: see report.json.

Signal and model

Causal filtering (2 Hz high-pass, 60 Hz notch and harmonics, 450 Hz low-pass), per-utterance channel z-scoring. Three strided residual convolution blocks (1,000 → 125 Hz), a depthwise convolutional position embedding, six pre-norm Transformer layers (d = 256, 4 heads), and a character CTC head (29 symbols). Trained 80 epochs on silent and voiced EMG with a mode embedding, AdamW (lr 5×10⁻⁴, cosine), bf16, and augmentations for gain, noise, electrode dropout and time masks. The checkpoint with the lowest dev WER (epoch 70) is used.

Decoding

Lexicon-constrained CTC prefix beam search (beam 32) with a word prior: an interpolated absolute-discount bigram (discount 0.75) trained on the training transcripts only. The prior weight and word bonus are tuned on the first 100 dev utterances only. Test sentences never influence any setting. Closed-N tasks keep test sentences, in index order, while their combined vocabulary fits N words, then pad the lexicon to exactly N with the most frequent training words.

Compute

NVIDIA GeForce RTX 4060 Laptop GPU, PyTorch 2.7.0. Median encoder time 12.7 ms per utterance at batch size 1.

5Metrics

WER is corpus-level: total word substitutions, insertions and deletions divided by total reference words. Word accuracy is 1 − WER. CER is the same over characters. Text is lowercased, numbers are spelled out, and punctuation is removed before scoring.

Confidence intervals are 95% percentile bootstrap intervals over utterances (2,000 resamples, fixed seed). Model comparisons use a paired bootstrap on the same utterances.

Information transfer rate treats each word as one selection from an N-word vocabulary (Wolpaw et al., 2002):

B = log₂N + P·log₂P + (1 − P)·log₂((1 − P)/(N − 1)) bits per word, ITR = B × words per minute

It assumes equally likely words and errors spread evenly over the other N − 1 words. Neither holds for sentences, and the formula rewards large N even at low accuracy, so we report it for comparison with BCI literature and lead with correct words per minute instead.

Correct words per minute = reference words per minute of recording × word accuracy. Real-time factor = compute time ÷ recording duration.

6Limitations

  • One speaker, one session setup, lab-grade electrodes. Cross-speaker and low-cost hardware results do not exist yet.
  • The dates-and-times test split is ours, not official. Its 43 utterances give a wide interval.
  • Speaking rate comes from read speech. Real use adds pauses, corrections and interface time.
  • Closed-N tasks select sentences that fit the vocabulary, which is easier than a user choosing freely within N words.

7The three models in Afono Nullpoint

Training

Afono sEMG Model

Facial sEMG to text. Metrics above.

Prototype

Afono Track Model

  • v0 in Nullpoint: MediaPipe iris landmarks, 9-point calibration, ridge regression, One Euro smoothing.
  • Scores accuracy and precision in degrees, and hit rate on a 12-target selection test.
  • No human sessions logged yet. Public benchmark: MPIIFaceGaze, leave-one-subject-out.
Prototype

Afono DOM Model

  • v0 Chrome extension: numbers every visible target and runs Tier 1 commands.
  • DOM-0 fixture (ours, 17 targets, 6 decoys): 100% precision, 100% recall. A sanity check, not a benchmark.
  • Next: precision and recall on the WebUI dataset, and the vocabulary size it hands the sEMG Model.

The combined system will be scored on web tasks by success rate, time per task, and selections per minute with Wolpaw ITR, against keyboard, mouse and eye-gaze baselines.

8Reproduce

pip install -r requirements.txt
python -m semg.prepare                      # index + cache (3.9 GB download first, see README)
python -m semg.train --out runs/base --notes "baseline"
python -m semg.evaluate --ckpt runs/base/best.pt --out runs/base/report.json
python -m semg.compare --profile demo-open --a runs/base/best.pt --b runs/<calib>/best.pt

Every run appends to runs/registry.jsonl. Per-utterance predictions are in runs/<run>/predictions.jsonl.
